# ai-dev-zoomcamp

GitHub repo: https://github.com/Chemoday/ai-dev-zoomcamp

## GitHub operations

Use the `ai-dev-zoomcamp-git-ops` skill
(`.claude/skills/ai-dev-zoomcamp-git-ops/SKILL.md`) whenever the user asks
to directly manipulate this repo on GitHub in any way — commit, push,
branches, PRs, issues, releases, deploys/workflow runs, etc. The
configured token is full repository-wide access.
